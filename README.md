# 社福去識別化工作流程版

在本機瀏覽器整理個案資料，協助社工於內部督導、外部 AI 或公開教學前辨識與覆核敏感內容。這是獨立衍生版本，原程式與參考來源見 [NOTICE.md](NOTICE.md)。

**[開啟線上工作台](https://paulchen01.github.io/welfare-deidentification/) · [社工試用與虛構 Word／PDF 範例](https://paulchen01.github.io/welfare-deidentification/trial.html) · [協作修改說明](CONTRIBUTING.md)**

線上版免登入，選取的個案文件在瀏覽器本機處理。網站資源由 GitHub Pages 提供；試用回饋只下載到你的電腦，不會自動送出。GitHub 儲存庫為公開專案，可在其他電腦 clone 或使用 AI 協作；Claude 入口為 `CLAUDE.md`，共用規則為 `AGENTS.md`，寫入與合併仍需授權。main 通過測試後自動更新社工試用網站，詳見 [部署說明](docs/DEPLOYMENT.md)。

## 開啟

Windows 離線包解壓縮後執行 `啟動工作台.cmd`，依畫面提示在瀏覽器開啟 `http://127.0.0.1:4178`。伺服器只綁定本機，關閉命令視窗即停止。不是直接雙擊 `index.html`。

原始碼環境需要 Node.js 與 npm：

```text
npm ci
npm run build
node scripts/serve-local.mjs
```

初次 `npm ci` 需要下載依賴；建置後的離線包自帶 OCR、PDF 處理與中文字型，處理個案不需連外。由同一版本原始碼建置的線上版與離線版使用相同處理邏輯；線上版仍需網路載入網站資源。既有 2026-10-18 Windows 離線 ZIP 尚未重建，不包含本次覆核工作流程改善。

## 四步驟

1. **加入資料**：選擇用途及文件種類，貼上文字或加入 TXT、MD、DOCX、XLSX、PDF。每批最多 10 份；每份 100 MB、抽取文字 200 萬字元上限，複雜壓縮文件另有結構限制。也可先使用虛構範例。
2. **人物與規則**：逐一確認姓名、角色與別名，或先預覽並批次加入人物清單。批次新增的人物仍須人工確認，不會自動認定別名或關係。不同文件預設不同案；只有明確選擇同案，才共用人物標記。同名或相同稱謂指向多人時，需自行拆分與人工判斷。
3. **人工覆核**：左右比較原文與處理後文字，依剩餘項目與未核對篩選逐項判斷。可改分類、選擇遮罩／概括／保留，或預覽後批次套用同詞設定；以完整字詞或反白選取補上遺漏。Excel 可對已抽取文字整欄標記。最後核對全部項目、閱讀全文及格式限制。
4. **匯出**：先查看每份文件的覆核、格式限制與二次掃描摘要；若新增疑似項目，回覆核修改，或確認適合目前用途後繼續。選擇 TXT、DOCX、XLSX 或 PDF（依輸入及結構檢查結果），按「下載這份文件」取得單檔，也可下載全部分享包或複製文字。單檔須完成該份覆核，批次須全部完成。PDF 重新生成文字版。需要還原時，另設密碼下載加密對照，勿與分享文件一起交付。

## 用途與人工責任

直接識別資料預設完整遮罩，不保留姓氏或號碼片段。內部督導預設保留部分服務情境但仍列入覆核；外部 AI 與公開教學會更積極遮罩或建議概括。日期、年齡與金額概括仍須依個案脈絡確認。

規則無法可靠辨識所有罕見職業、地點、家庭組合或事件。選擇公開教學也不等於保證完全匿名。若事件本身足以辨識，應自行重寫或停止分享。

車牌、LINE ID 與統編採明確欄位標籤辨識，例如「車牌：ABC-1234」「LINE ID：social_demo」「統編：04595257」。普通英數代碼或八位數字不會單靠外觀全部列入；有標籤但檢核不符的統編可列為候選，仍須人工確認。

人物清單每行一人，可只填姓名，或用 Tab 分隔「姓名、角色、別名」，多個別名用頓號分隔。先預覽再加入；最多 100 行，每個姓名／別名最多 120 字元、每人最多 20 個別名。同案完全同名者會提示略過，不修改既有人物；有錯誤行時須先修正才會加入整批。清單只留在本頁記憶體。

覆核清單每批顯示最多 30 項；「核對本批顯示的項目」只處理畫面這一批，匯出仍檢查整份文件。同詞批次套用只納入目前文件中原文、原分類與人物識別皆相同的項目，先顯示影響與排除數，再由使用者確認。

「復原最近操作」保留本頁記憶體內最多 20 步，涵蓋處理方式、分類、同詞批次與手動標記。復原後受影響項目須重新核對，全文覆核也會撤銷；改用途、人物或規則、重新分析及清除資料都會清掉舊操作歷史。焦點在覆核工具列或項目內時可使用 ↑／↓ 移動、R 切換核對、Ctrl／⌘ + Z 復原；輸入欄位與選單保留正常編輯鍵。

匯出前會使用同一套本機規則與人物候選辨識，再檢查處理後文字，包括自行填入的概括文字。人工核對後選擇保留的原文會另列數量；其他位置出現相同值仍會檢查。新增疑似項目的確認只對目前文件及判斷狀態有效，修改、復原或重新分析後失效；單檔、分享包與複製皆適用。若已選定遮罩的原值仍殘留，確認也不能解除阻擋。這仍無法找出所有未知姓名或間接識別線索。

## 格式涵蓋

| 格式 | 供覆核內容 | 匯出原則 |
| --- | --- | --- |
| TXT / MD | 全部文字 | 覆核後可輸出文字 |
| DOCX | 支援的本文、表格、頁首頁尾文字 | 檢查隱藏封裝內容；未涵蓋批註、修訂、圖片、內嵌或其他內容時阻止原格式輸出，仍可覆核後輸出已抽取文字 |
| XLSX | 支援的文字儲存格 | 數值、公式、隱藏區域或其他未涵蓋內容須查看限制；不把抽取文字當作完整活頁簿。可安全輸出的文字活頁簿使用中性工作表名稱 |
| PDF | 文字層與逐頁 OCR 的結果 | 輸出重新產生的辨識文字，預設不保留圖片。OCR 可能誤字或漏字；無法讀取的頁面會標示不完整 |

純文字版本只保留抽取內容，不保留版面、圖片、公式等。格式限制會顯示於覆核頁。完整支援矩陣與技術測試見 `docs/task-2-report.md` 與 `docs/verification.md`。

## 還原與設定

- **新版加密對照**：AES-256-GCM、PBKDF2-SHA256。密碼至少 8 字元，建議較長密語。對照檔內含原值與原檔名，需獨立保管，密碼無法復原。
- **逐字還原**：需與當初匯出內容完全相同的文字，包含換行。請保留 TXT 版本以供還原。經 AI 改寫、增刪或重新排版的文字會被拒絕，避免錯誤套用。只能還原文字，不重建原始文件版面。
- **原版 CSV**：另提供相容入口，核對標記的類別與代碼。CSV 沒有整份文件雜湊，不能證明來源或內容完整，須自行檢查。新版不輸出未加密 CSV 對照。
- **機構範本**：只包含用途與固定前綴的個案號規則，不包含人物清單、個案原文或還原對照。名稱與標籤請勿填個案資料。套用範本後需重新覆核。

## 資料生命週期

個案文字、人物與對照只存在本頁記憶體，不寫入 localStorage、IndexedDB、伺服器或紀錄檔。重新整理、關閉頁面或「結束並清除」會清除本次工作並回到通用設定；需要保留機構規則時請先下載範本。下載的檔案、作業系統剪貼簿與瀏覽器下載紀錄需使用者自行管理。長時間工作前請先完成匯出，頁面不自動儲存。

隨附本機伺服器只提供 GET/HEAD 靜態資源，拒絕資料上傳，並設定內容安全政策限制連外來源。這不涵蓋瀏覽器擴充套件、其他應用程式或作業系統的行為。

## 開發與驗收

```text
npm test
npm run build
npm audit
```

`tests/welfare` 包含社福規則、60 筆合成資料、人物歧義與隔離、匯出殘留、加密還原、設定輸入與文件結構測試。合成資料是可重現的回歸測試，不能用通過率宣稱真實文件的辨識正確率。

本次改善的操作、字級對比、長清單、手機版與實際下載回讀證據見 [覆核工作流程改善驗收](docs/review-improvements-verification.md)。

本版仍需 3–5 位實務工作者試用，紀錄表見 [docs/pilot-checklist.md](docs/pilot-checklist.md)。尚未安排或宣稱完成實務試用。
