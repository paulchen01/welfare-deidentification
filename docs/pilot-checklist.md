# 實務試用紀錄表（尚未執行）

本機技術檢查不能取代社工實務驗證。建議由 3–5 位實務人員使用虛構或已合法處理的資料進行試用，不需提供真實個案給開發者。

| 項目 | 紀錄內容 |
| --- | --- |
| 服務領域與經驗 | 家庭、兒少、老人、身障、心理健康、保護；年資 |
| 任務與用途 | 內部督導、外部 AI、公開教學 |
| 文件種類 | 服務紀錄、會議紀錄、名冊；原格式 |
| 人物連結錯誤 | 哪些姓名或稱謂被錯連、漏連；是否能修正 |
| 漏遮與誤遮 | 請用虛構替代值記錄類型、位置與原因 |
| 間接辨識風險 | 稀有事件、關係、地點與職業的組合 |
| 格式風險理解 | 是否理解只匯出抽取文字、圖片移除等限制 |
| 分享及還原 | 是否誤把對照檔交出；能否完成正確版本還原 |
| 耗時與操作障礙 | 初次完成時間；不能理解的詞；中斷點 |
| 修正與複測 | 優先度、負責人、版本、複測結果 |

正式使用前，由機構確認適用目的、可接受風險、資料保管與對外分享程序。本工具不代替機構決策。
